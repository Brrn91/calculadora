# 🚀 Projeto Calculadora - HTML, CSS e JavaScript

Este projeto foi elaborado como forma de **treinar e consolidar meus conhecimentos em HTML, CSS e JavaScript**, aplicando conceitos de estrutura, estilização e interatividade em uma aplicação prática.

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura semântica e organização do conteúdo
- **CSS3** – Estilização, layout e responsividade
- **JavaScript (ES6+)** – Interatividade e manipulação do DOM
- **Flexbox / Grid** para organização do layout
- Fonte personalizada via **Google Fonts**

---

## ⚙️ Funcionalidades

- ✅ Estrutura organizada e semântica
- ✅ Layout responsivo para diferentes tamanhos de tela
- ✅ Interações dinâmicas utilizando JavaScript
- ✅ Código limpo e bem estruturado
- ✅ Foco em boas práticas de desenvolvimento front-end
